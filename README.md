# 🌿 Ecoficina — Recondicionamento Sustentável de Peças Automotivas

> Solução tecnológica inteligente que conecta oficinas mecânicas, centros de manufatura aditiva (impressão 3D industrial) e proprietários de veículos para recondicionamento e fabricação sob demanda de peças automotivas com polímeros reforçados.

---

## 🚀 Sobre o Projeto

A **Ecoficina** propõe a transformação da cadeia de reposição de peças automotivas e de transporte pesado (frotas, caminhões Iveco, utilitários):
- **Economia de até 60%** em comparação a peças originais novas.
- **Redução de pegada de carbono**: até **38 kg de CO₂ evitados** por peça recondicionada.
- **Menor tempo de parada de frota**: peças impressas localmente sob demanda.
- **Materiais de alta performance**: polímeros técnicos reforçados com fibra de carbono (Nylon CF, ABS Reforçado, PETG, TPU).

---

## ✨ Funcionalidades

- **Hero Dinâmico em Vídeo**: Sequência contínua com crossfade dos vídeos em alta resolução demonstrando caminhões e processos de manufatura 3D.
- **Landing Page Interativa**:
  - Explicação do fluxo de recondicionamento em 3 etapas.
  - Calculadora de impacto ambiental e financeiro.
  - Catálogo de peças recondicionáveis com filtros por categoria e busca em tempo real.
  - Mapa interativo com oficinas credenciadas e centros de impressão.
- **Dashboard do Usuário**:
  - Visão geral de frotas e serviços.
  - Catálogo de solicitação e orçamento.
  - Agendamento de diagnóstico e coleta.
  - Histórico de impacto ambiental (Eco Score).
  - Localizador de oficinas parceiras com Leaflet Maps.
- **Painel B2B da Oficina**:
  - Gestão operacional de serviços.
  - Fila de impressão 3D em tempo real.
  - Controle de estoque de filamentos e peças.
  - Métricas financeiras e relatórios gráficos com Chart.js.

## 💻 Como Rodar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/adrianomazettosenai/ecoficina.git
   cd ecoficina
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. Acesse no navegador: `http://localhost:5173/`
